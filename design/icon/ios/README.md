In the iOS shell worktree, copy this folder to `<app target>/Assets.xcassets/AppIcon.appiconset/` (replace any existing one; the folder name must be `AppIcon`), make sure the asset catalog is in the app target's Resources build phase, and set the build setting `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon` (Xcode 15+ single-size format: one 1024 px universal image plus dark and tinted variants; nothing else is needed, and the PNGs are full-bleed, opaque, with no rounded corners because iOS masks them). With a hand-written Info.plist add no icon keys; with XcodeGen or a project.yml list the catalog under `resources` and set the setting above. Regenerate with `sh tools/make_icons.sh` in the main checkout.
