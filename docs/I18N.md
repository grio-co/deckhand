# Internationalisation

- Language is a setting. A `.dhlang` module carries labels, plural rules, help/support docs and
  needed fonts for one language; installing it is enough.
- Skins reference string keys, never literal text, so any skin works in any language.
- Layout tolerates text expansion; right-to-left scripts supported. English is the fallback.
- Locale-aware numbers, dates and times.
