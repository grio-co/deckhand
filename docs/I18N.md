# Internationalisation

- Language is a setting. A `.dhlang` module carries labels, help documents and the plural/number
  conventions of one language; installing it (dropping it in the language folder) is enough.
- Skins and the app reference string ids, never literal text, so any skin works in any language.
- Layout tolerates text expansion; right-to-left languages declare `@dir rtl`. English is the fallback.
- Locale-aware numbers; plural rules follow CLDR. Dates and times are not yet covered.

Code: `src/i18n/include/deckhand/i18n/i18n.hpp`. Shipped packs: `resources/lang/`.

## Pack format (`.dhlang`)
A `.dhlang` is either one UTF-8 text file, or a directory holding `lang.dhl` (same syntax) plus
`help/<topic>.md` Markdown documents addressed by topic id. Limits: 4 MiB file, 20000 strings, 16 KiB
per string, 512 help files of 256 KiB.

    # comment
    @lang de              BCP-47 tag (required): de, pt-BR, zh-Hans
    @name Deutsch         native name
    @dir ltr              ltr | rtl
    @version 1.0
    @fallback en          optional extra fallback tags, comma separated
    deck.sync = SYNC
    browser.tracks = {count, plural, one {# Titel} other {# Titel}}

Ids are `[A-Za-z0-9_.-]`, up to 128 chars. `\n` and `\t` are escapes; `\{ \} \\ \#` are literals in a message.

## Fallback chain
`pt-BR` -> `pt` -> each tag in the packs' `@fallback` lists (recursively) -> `en` -> the id itself.
Missing strings therefore never block the UI.

## Messages (ICU-MessageFormat subset, original implementation)
- `{name}` substitutes an argument (numbers use locale formatting).
- `{n, number}` / `{n, number, 2}`: locale number, optional fixed decimals (default up to 3).
- `{n, plural, =0 {none} one {# file} other {# files}}`: `=N` exact match first, then the CLDR category
  (`zero one two few many other`); `other` is required; `#` is the number. Nested placeholders allowed.
- `{g, select, a {..} other {..}}`: text selection.
Plural rules: en, de, nl, it, es, pt, fr, ru, uk, pl, cs, sk, tr, ar, he, ja, zh, ko (plus vi/th/id: other);
unknown languages use English rules. Number symbols per language (fr narrow-nbsp grouping, de/it/es/nl
dot grouping, es/pl no grouping below 5 digits, ...).

## API
`Catalog`: `load_builtin(path)`, `load_directory(dir)`, `add_pack`, `set_language(tag)`, `tr(id[, args])`,
`help(topic)`, `direction()`, `available()`. Readers are lock-light and thread-safe: `set_language` and
`add_pack` publish a new immutable snapshot, so the UI thread can read while settings change.
`validate(pack, english)` reports missing/extra ids, placeholder mismatches, syntax errors and missing
help topics. Tests require every shipped pack to validate clean.

## Id conventions
`app.*`, `status.*`, `deck.*`, `mixer.*`, `browser.*`, `browser.col.*`. Ids are stable: never reuse an id
for a different meaning; add a new one. Skins use `@id` references (see SKINS.md).
